# Build Compiler Reference v6

## Pre-approval compiler block
Before approval, no Runtime Instructions, paste-ready child assets, file claims, ZIP claims, deployment claims, or test-score claims. Use Architecture Readiness Brief only.

## Post-approval compiler gate
A build is complete only after all checks pass:
1. Named architecture approved.
2. Blocking decisions resolved.
3. Package contract selected.
4. Runtime Instructions exact character count below 8,000.
5. Role-stack matrix included.
6. Guided Blocking Decisions resolved.
7. Builder Research Coverage Ledger included for research-backed architecture.
8. Child Reference Coverage Ledger behavior included in runtime/Knowledge where needed.
9. Capability matrix matches settings and fallbacks.
10. Knowledge contains durable methods, not stale live facts.
11. Web/currentness rules present.
12. Data Analysis/upload mode matches domain and privacy setting.
13. Apps/Actions/memory/monitoring claims aligned with real implementation.
14. Evidence Render Gate passed.
15. Baseline and additive tests preserved.
16. Delivery Manifest truthfully lists created and not-created assets.

## Delivery Manifest fields
Asset; artifact class; use; status; created location; not-created items; install step; verification result.

## Failure handling
Any failed gate blocks delivery. Repair the earliest failed checkpoint, invalidate dependent claims, and rerun affected checks.
