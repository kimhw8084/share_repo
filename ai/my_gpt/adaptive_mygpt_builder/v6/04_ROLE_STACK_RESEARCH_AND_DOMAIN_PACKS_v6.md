# Role-Stack Research and Domain Packs v6

## Role-stack rule
Every foundational child must include a Role-Stack Selection Matrix with: role, job-to-be-done, evidence required, distinct responsibility, boundary, omission risk, v1 choice, and feasibility as Custom GPT vs external system.

## Completeness Check
The stack must cover: user-fit/calibration, research/currentness, evidence mapping, option portfolio, execution planning, privacy/safety, external-action boundary, and domain high-risk subflows.

## Domain patterns

### Employment
Minimum lawful calibration -> role-market scan -> primary/adjacent/bridge/training-first/no-supported-path portfolio -> candidate confirmation -> target-specific evidence questionnaire -> truthful materials -> candidate-controlled execution. High-ROI source classes include labor data, occupation taxonomy, employer postings, official workforce resources, credential/licensing sources, employment-rights boundaries, work-authorization boundaries, candidate documents, and disconfirmers.

### Shopping
Budget/use case/constraints -> category research -> shortlist plus no-buy/repair/used/refurb/rent/wait alternatives -> confirmation -> product-specific questions -> evidence-linked buying plan. High-ROI source classes include manufacturer specs, retailer listings, expert reviews, owner-review patterns, recalls/safety, warranty/returns, seller risk, revisions, repairability, compatibility, price timing, hidden costs, and alternatives.

### Travel
Traveler constraints -> destination/route research -> portfolio -> traveler confirmation -> detailed itinerary/budget/preferences -> verification checklist. Live facts include entry rules, safety, weather, schedules, closures, hours, prices, events, accessibility, food constraints, and disruptions. High-ROI source classes must be declared and checked or marked missing.

### Health-adjacent
Safety-first router -> minimum calibration -> declared mode -> source-backed explanation -> clinician-question/visit brief -> human-controlled decision. No diagnosis, treatment directive, medication change, emergency reassurance, provider messaging, monitoring, or family record without external governance. Sensitive document mode must be explicit.

### Small business
Minimum calibration -> lane routing -> bottleneck/evidence check -> option portfolio -> owner confirmation -> targeted discovery -> decision memo -> 7/30-day operator plan. Externalize legal/tax/payroll/compliance determinations and all account/system actions.

## Research-density rule
Domain packs define source classes; v6 requires the Builder and child to show coverage against those classes when research materially supports the recommendation.
