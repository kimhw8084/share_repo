# Industry Archetype Checklists and Query Bundles

Version: 1.0  
Use this file to prevent missing critical nodes when the user asks about a broad or unfamiliar industry. This file is not a substitute for research. It is a pre-research and pre-final checklist.

## Objective

Different industries fail in different ways. Technology reports miss power and integration. Pharma reports miss payers and manufacturing. Commodity reports miss grades and treatment charges. Nuclear reports miss regulation and fuel cycle. Finance reports miss liquidity, covenants, and default cycles.

Use the relevant archetype checklist before research and again during self-audit.

## Archetype 1: Technology infrastructure

Example benchmark: AI infrastructure.

Common nodes to check:

- GPU or accelerator
- HBM
- Advanced packaging
- Semiconductor equipment
- Data center
- Power
- Cooling
- Networking
- Optics
- Cloud platform
- Model layer
- Inference economics
- Enterprise adoption
- Security/compliance
- Developer workflow
- Final customer budget owner

Technology infrastructure query bundle:

- `[industry] value chain GPU HBM advanced packaging data center power cooling networking optics`
- `[industry] capex guidance data center power interconnection`
- `[industry] inference economics enterprise adoption security compliance`
- `[industry] earnings call demand capacity bottleneck margin`
- `[industry] optical networking switch power cooling lead time`

## How to use this file

Before research:

1. Identify the closest archetype.
2. Use the checklist to build a hypothesis graph.
3. Use the query bundle to guide deep research.

Before final answer:

1. Check whether any archetype-critical node is missing.
2. If missing, add it, exclude it with reason, or mark evidence insufficient.
3. Do not force irrelevant nodes into the report.

## Anti-overfitting rule

These are benchmark checklists, not fixed templates. Use them to avoid obvious omissions, then adapt to the specific industry.
